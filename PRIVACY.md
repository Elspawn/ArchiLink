# Privacy Policy

**Last updated:** July 27, 2026

## Overview

ArchiLink is a Discord bot that bridges an Archipelago multiplayer server with a Discord server by relaying messages and game events.

The bot is designed to collect and store only the minimum amount of information required for its operation.

## Data Stored

ArchiLink stores the following information:

### Configuration

A local configuration file containing information required to connect to:
- The Discord bot account
- The Archipelago server

This may include server addresses, authentication information, and channel mappings.

### Runtime Game Data

To function correctly, the bot stores certain information related to the connected Archipelago session, such as:
- Player gametags
- Game names
- Received items
- Other session-related data necessary for synchronization and message relaying

This data is used solely for the operation of the bot.

## Discord Messages

Messages sent in the configured Discord channels may be relayed to the connected Archipelago server, and messages from the Archipelago server may be relayed to Discord.

The bot does not permanently store message history beyond what is necessary for normal operation.

## Data Sharing

ArchiLink does not sell, share, or transmit collected data to any third-party services, except for the normal communication required with Discord and the configured Archipelago server.

## Data Retention

Stored data remains on the machine hosting the bot and is retained only for as long as the bot is in use or until the data is manually removed.

## Contact

If you have any questions regarding this Privacy Policy, please contact the maintainer of the ArchiLink bot or the administrator of the server using it.
